1)what is website
:-  A website is a collection of web pages written in HTML. To make it accessible worldwide, 
    it must be stored on a computer connected to the Internet 24/7. These computers are called web servers.

    component of website

    1) frontend 2)backend 3)databases 4)api calls 5)hosting and domain

    Think of a website like a restaurant 🍽️:

    Frontend → Menu + dining area (what you see)
    Backend → Kitchen (where work happens)
    Database → Storage (ingredients)
    API → Waiter (communication)
    Hosting → Building/location


2)How Browser works
:-  i) we have to enter URL
    ii)DNS lookup (domain name service) browser ask where is this website it convert url into ip address
    iii)request sent to Server via http/https request server receive it
    iv)server respond with html css js file
    v)rendering 
    :- parse HTML - dOM 
       parse Css 
       combine - render tree
       layout calculate positions
       paint - show on screen

    vi)JavaScript Execution
    :- js runs using engine like V8
        make page interactive
            Clicks
            Animations
            API calls


full flow 
URL -> DNS -> SERVER REQUEST -> RESPONSE -> RENDER -> DISPLAY

4)what is clien-Server
:-  client server is a model where:
    client request something
    server provide that something

    client(request Sender)
    :-A client is usually 
        -web browser like google chrome
        -mobile app
        -any device requesting data
    
    server(response Provider)
    :-A server is 
        -A computer/system that store data
        -processes request
        -Sends responses

    how it works
    1)client send request
    2)server receive request
    3)server processes it
    4)server send response
    5)client display result


5)HTTP basics
:- HTTP (HyperText Transfer Protocol) is the rule/system that allows communication between:
    -client
    -server
    it defines how request and responses are sent

    method -> what you want to do
    URL -> where to go
    Headers -> extra info
    Body ->data

    Http Methods(Very Important)
    GET -> Fetch data
    POST -> Send data
    PUT  -> Updata data
    DELETE -> Remove Data

    HTTP response(from server)
    -Status code 
    200 -> Success
    404 -> Not Found
    500 -> Server Error
    301 -> Redirect 





    http -> not secure
    https -> secure(encrypted)

# What is Semantic Html ?
:-  Semantic html means using meaningful tags that describle the content clearly
    instead of using <div>, we use tags like:
        <Header>
        <footer>
        <article>
        <section>
    this tags tell the browser + dev what the content means

    eg:
    <header>Top section</header>
    <nav>Navigation links</nav>
    <main>Main content</main>
    <section>Section</section>
    <article>Article</article>
    <aside>Sidebar</aside>
    <footer>Bottom section</footer>

    why Semantic Html is Important
    1. Better SEO
    2. accessibility
    3. Clean code
